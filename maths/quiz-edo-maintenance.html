Méthode — équation \( a\,y' + b\,y = c \)
  1. Solution homogène. On résout \( a\,y' + b\,y = 0 \). En séparant les variables : \( \dfrac{y'}{y} = -\dfrac{b}{a} \), d'où \( y_0(t) = C\,e^{-(b/a)\,t} \).
  2. Vérification de la solution particulière. On propose une solution particulière \(y_p\) (le plus souvent une constante). Comme \( y_p' = 0 \), on vérifie qu'elle est bien solution en la substituant dans l'équation complète : \( b\,y_p = c \), soit \( y_p = \dfrac{c}{b} \).
  3. Solution générale. C'est la somme des deux : \( y(t) = y_0(t) + y_p = C\,e^{-(b/a)t} + \dfrac{c}{b} \).
  4. Solution unique. La condition initiale \( y(0) \) permet de déterminer \(C\) : \( C = y(0) - \dfrac{c}{b} \).
Vocabulaire courant en électrotechnique : \(y_0\) est appelée régime libre (ou transitoire), \(y_p\) le régime permanent (valeur atteinte une fois le régime établi).
Voir un exemple résolu, étape par étape

On modélise le refroidissement d'une carcasse de moteur par \( 10\,\theta'(t) + \theta(t) = 22 \) (\(t\) en minutes), avec \( \theta(0) = 82\,^{\circ}\mathrm{C} \).

  1. Solution homogène. \( 10\theta' + \theta = 0 \Rightarrow \dfrac{\theta'}{\theta} = -\dfrac{1}{10} \Rightarrow \theta_0(t) = C\,e^{-t/10} \).
  2. Vérification de la solution particulière. On propose \( \theta_p = 22 \). Comme \( \theta_p' = 0 \) : \( 10 \times 0 + 22 = 22 \) ✓. \(\theta_p = 22\) est bien solution.
  3. Solution générale. \( \theta(t) = C\,e^{-t/10} + 22 \).
  4. Solution unique. \( \theta(0) = 82 \Rightarrow C + 22 = 82 \Rightarrow C = 60 \). D'où \( \theta(t) = 60\,e^{-t/10} + 22 \).
